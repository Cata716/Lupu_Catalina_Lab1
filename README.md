# ASP.NET Core Web Application - Lab 1

This repository contains the source code for my first ASP.NET Core web application, developed as part of a programming environments course at FSEGA.

## Project Overview

This is a basic ASP.NET Core Web App using Razor Pages, created to demonstrate:
- Setting up a development environment with Visual Studio 2022
- Creating an ASP.NET Core web application
- Version control with Git and GitHub
- Working with branches for iterative development

## Technology Stack

- **Framework**: ASP.NET Core (Razor Pages)
- **IDE**: Visual Studio 2022 Community Edition
- **Language**: C#
- **Version Control**: Git & GitHub

## Project Structure

The application follows the standard ASP.NET Core Razor Pages structure:
- `Pages/` - Contains the Razor pages and their code-behind files
- `wwwroot/` - Static files (CSS, JavaScript, images)
- `Program.cs` - Application entry point and configuration
- `appsettings.json` - Application configuration settings

## Getting Started

### Prerequisites

- Visual Studio 2022 Community Edition or higher
- .NET SDK (Long Term Support version)
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Cata716/Lupu_Catalina_Lab1.git
   ```

2. Open the solution in Visual Studio 2022

3. Restore NuGet packages (Visual Studio will do this automatically)

4. Run the application by pressing F5 or clicking the green play button

5. When prompted, accept the SSL certificate for local development

### Running the Application

The application will launch in your default browser at `https://localhost:5212`
